# Plans

Two kinds of files live here. Both dated `YYYY-MM-DD_topic.md`. Follow docs/WRITING_RULES.md.

| Kind | Who reads it | What goes in it |
|---|---|---|
| `*_research-plan.md` | Lead + AI manager | Full working plan. Methods detail, draft feedback, open questions, decisions pending. |
| `*_team-brief.md` | The whole team | What the research is and what we are doing. Zero context needed. No feedback, no open questions, no to-dos. |

The newest file of each kind is the current one.
