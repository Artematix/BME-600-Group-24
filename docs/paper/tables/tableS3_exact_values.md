## Words used in the table (not for the paper block)

- Typical participant = the median, the middle participant when all are put in order. Rows a to g give the median.
- Middle half = from quartile 1 to quartile 3 of the participants.
- 95 % interval = the range the true value most likely sits in. It comes from re-drawing the participants at random 2,000 times.
- Needed correction = a dose decision where the calculator gives more than 0.5 units with the true glucose. Withheld = it gives 0 units with the shown glucose.
- High episode = 15 minutes or more with the true glucose above the line (180 or 200 mg/dL).
- Pair = one sensor value with the meter value for the same moment. Report pair = the same two values read from a report text.

All 15 letters were found. Three smaller things were not.

- a, b, g. The total number of needed corrections. The files hold each participant's own share only. So the rows give the number of participants, not a count of corrections.
- o. The race and ethnicity counts on the paper's own total of 3,382,071 reports. The count tables add up to 3,379,280 reports, which is 2,791 fewer. Why the totals differ was not found. The two percentages are the same on either total (0.26 and 0.34 %).
- o. How many reports record race or ethnicity or both. The files give the two fields one by one. The text says "race or ethnicity", and each field alone is about 3 in 1,000.
