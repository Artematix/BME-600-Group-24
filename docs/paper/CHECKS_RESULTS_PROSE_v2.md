## Words

- Pair = one sensor value with the meter value for the same moment. Report pair = the same two values read from a report text.
- Median = the middle value. The typical participant is the median participant.
- MARD = the average size of the sensor's error in % of the meter value, ignoring direction.
- Calibrate = enter a meter value into the sensor so that the sensor adjusts itself.
- p = the chance of seeing a result this strong when there is no real effect. Under 0.05 is the usual line.
- CGM+BGM arm = the trial arm that was told to check with a meter before dosing. CGM-only arm = the other arm.
