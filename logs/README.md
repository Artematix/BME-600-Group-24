# Logs

One file per work session or big agent task. Keep each under ~40 lines.

Filename: `YYYY-MM-DD_HHMM_short-topic.md`
Example: `2026-10-07_1300_repo-setup.md`

Files sort by date automatically. No index needed.

## Template

```
# <topic>

Date: YYYY-MM-DD HH:MM
Who: manager / agent (what kind)
Asked by: <user or manager>

## Asked
- what the task was

## Done
- files created or changed (paths)
- one-line result

## Decisions
- choices made and why (one line each)

## Open questions / next
- anything unresolved
```

## What to log
- Any agent run that produced a file.
- Any decision about research direction, data, or methods.
- Anything a teammate might later ask "why did we do that?"

## What NOT to log
- Tiny edits, typo fixes, reading files.
